Method overview

Purpose of the FFT Module

The FFT + Baseline Analysis module smooths calcium signals using a low-frequency reconstruction based on the Fast Fourier Transform, detects peaks in the smoothed signal, and calculates metrics for each calcium transient. It then evaluates how these metrics change when the baseline definition is modified.

In practical terms, the module addresses three questions: which events are present, how large each event is, and how robust those conclusions are to the selected baseline and smoothing settings.

Important: FFT smoothing should not create artificial events. It should reduce high-frequency noise while preserving the timing, amplitude, and overall morphology of biologically plausible calcium transients.

Before interpreting results

0. Mathematical notation used in this guide

Raw and smoothed signals

For a selected ROI, the application works with a time series:

\[x = (x_1, x_2, \ldots, x_n), \qquad x_i = x(t_i)\]

After FFT smoothing, the reconstructed signal is:

\[\hat{x} = (\hat{x}_1, \hat{x}_2, \ldots, \hat{x}_n)\]

The difference between the two signals is the residual:

\[r_i = x_i - \hat{x}_i\]

Event, baseline, and amplitude

For event \(j\), let \(t_{p,j}\) denote the peak time and let \(b(t)\) denote the baseline.

\[\text{Amplitude}_j = \hat{x}(t_{p,j})\]

\[\text{Amplitude Above Baseline}_j = \hat{x}(t_{p,j}) - b(t_{p,j})\]

For dynamic baselines, \(b(t)\) varies over time. For static baselines, \(b(t)=b\) for all \(t\).

Determines whether the application uses internally generated simulated data or expects an external input file. Use Yes for demonstrations and rapid testing. Use No to analyze your own calcium-imaging data.

2. Dataset

The dataset must contain a time column as the first column, followed by ROI or calcium-signal columns. The module accepts .csv, .tsv, and .json files. 

Time,ROI_1,ROI_2,ROI_3

Recommended check: confirm that the time column is numeric, sorted in ascending order, and expressed in a consistent unit. Frequency is calculated as the number of detected events divided by the total recording duration.

3. Region of Interest (ROI)

Selects which signal column will be analyzed. For example, if the dataset contains Time, ROI_1, ROI_2, ROI_3, then ROI = 1 uses ROI_1, ROI = 2 uses ROI_2, and so on.

4. FFT Low-Frequency Fraction

This control defines the fraction of low-frequency components retained when reconstructing the signal. The goal is to remove fast components associated with noise while retaining slower components associated with calcium-transient morphology.

If the signal contains \(n\) time points, the number of unique positive-frequency components is:

\[n_{pos}=\left\lfloor\frac{n}{2}\right\rfloor+1\]

For an FFT fraction \(f\), the application approximately calculates:

\[k_{keep}=\max\left(1,\left\lfloor f\,n_{pos}\right\rfloor\right)\]

The low-frequency components \(k=0,1,\ldots,k_{keep}-1\), together with their symmetric negative-frequency components, are retained.

Value of \(f\)Expected effectPotential risk
Low, for example 0.10Strong smoothing.May remove narrow peaks or reduce event amplitudes.
Intermediate, 0.20–0.30Compromise between noise reduction and morphological preservation.Should be visually validated.
High, 0.40–1.00Retains more detail from the original signal.May retain noise that could be interpreted as events.

4.1. Keep Mean (DC Component)

The DC component represents the global mean of the signal. When retained, the smoothed signal preserves the average fluorescence level. When removed, the reconstruction may be centered around zero, altering baseline interpretation.

6. Baseline

The baseline is the reference level used to measure amplitude, \(\Delta F/F_0\), AUC, and event widths. Changing the baseline can alter both the number of accepted events and the resulting metric values.

6.1. Standard Definition

Uses the mean of the initial fraction of the signal: \(b = \frac{1}{m}\sum_{i=1}^m \hat{x}_i\), where \(m = \lfloor n\cdot\text{Initial Trace Fraction}\rfloor\).

6.2. Low-Fluorescence Region Baseline

Sorts the signal values and calculates the baseline from the lower fraction of the distribution. This is useful for approximating a resting level when a stable initial interval is not available.

6.3. Rolling Percentile Baseline

For each time point \(t\), a local window is defined and a low percentile is calculated. This produces a dynamic baseline \(b(t)\), which is useful when the signal exhibits slow drift.

6.4. Event-Specific Baseline: Left-Right FFT Minima

For each event, the application identifies one local minimum before the peak and one after the peak in the smoothed signal. The line connecting these minima defines a local baseline for that event.

6.5–6.7. Legacy / Min

Median signal, Mean signal, and Min are simple global reference values. They are useful for comparison but may be sensitive to transients, noise, or baseline drift.

7. Area Under the Curve (AUC)

Enables calculation of the area above the baseline. AUC summarizes the total time-integrated calcium signal.

For either a static or dynamic baseline:

\[\mathrm{AUC}=\int \max\{\hat{x}(t)-b(t),0\}\,dt\]

For discretely sampled data, the application uses a trapezoidal approximation:

\[\mathrm{AUC}\approx\sum_i \frac{\Delta t_i}{2}\left(y_i+y_{i+1}\right),\quad y_i=\max\{\hat{x}_i-b_i,0\}\]

A large AUC may indicate higher-amplitude, longer-duration, or more frequent events. It should therefore be interpreted together with peak count, amplitude, and width metrics.

8. Raw Data

Shows or hides the raw signal overlaid on the FFT-smoothed signal. This is a visual quality-control step: the smoothed signal should follow the underlying trend without retaining excessive noise or removing biologically meaningful events.

9. Full Width at Half Maximum

Enables visualization and calculation of the full width at half maximum. FWHM estimates the duration of an event at half of its baseline-corrected amplitude.

FWHM

\[\text{Half maximum level}=b(t_p)+\frac{x(t_p)-b(t_p)}{2}\]

\[\mathrm{FWHM}=t_{right}^{FWHM}-t_{left}^{FWHM}\]

FWHP

FWHP uses prominence rather than a global baseline:

\[\text{Half prominence level}=x(t_p)-\frac{\mathrm{Prominence}}{2}\]

\[\mathrm{FWHP}=t_{right}^{FWHP}-t_{left}^{FWHP}\]

10. Optional Sigmoid Modeling

Sigmoid models are optional. They do not modify FFT smoothing or the primary peak-detection procedure; instead, they provide additional metrics derived from fitting a smooth curve around each event.

10.1. Single Sigmoid

\[g(t)=B+\frac{A}{1+e^{-k(t-t_0)}}\]

Used to refine onset, rise time, and rise rate. The parameter \(k\) controls the steepness of the rise, while \(t_0\) identifies the point of maximum slope.

10.2. Double Sigmoid

\[g(t)=B+A\left(\frac{1}{1+e^{-k_1(t-t_1)}}-\frac{1}{1+e^{-k_2(t-t_2)}}\right)\]

Models both the rising and decay phases. It provides metrics for offset, duration, decay time, and decay slope.

Sigmoid outputDefinitionInterpretation
SingleSigmoid_Slope_at_t0Maximum slope of the single-sigmoid fit: \(A k/4\).A larger value indicates a more abrupt rise.
SingleSigmoid_R2Goodness of fit for the single-sigmoid model.A value close to 1 indicates that the rising phase is well approximated by a sigmoid.
DoubleSigmoid_Decay_TimeDecay time from the peak to the fitted offset or right-side minimum.A larger value indicates a more prolonged recovery phase.
DoubleSigmoid_Decay_SlopeDecay slope, conventionally reported as a negative value.A more negative value indicates faster decay.

13.3. Fourier Analysis

This tab explains the FFT smoothing procedure used by the module. The signal is decomposed into frequency components, low-frequency components are retained, and the smoothed signal is reconstructed.

Transform and reconstruction

The FFT represents the signal as a combination of sinusoidal waves:

\[X_k=\sum_{t=1}^{n} x_t e^{-2\pi i k(t-1)/n}\]

The low-frequency reconstruction can be written as:

\[\hat{x}_t=a_0+\sum_{k=1}^{k_{keep}-1}\left[a_k\cos\left(\frac{2\pi k(t-1)}{n}\right)+b_k\sin\left(\frac{2\pi k(t-1)}{n}\right)\right]\]

14. Baseline Sensitivity Analysis

This tab recalculates metrics from the same FFT-smoothed trace using multiple baseline definitions. Its purpose is not to claim that one baseline is universally correct, but rather to assess whether the conclusions depend strongly on the chosen reference.

Automatic sensitivity index

The application calculates coefficients of variation for amplitude, AUC, and FWHM:

\[CV(\%)=100\cdot\frac{\mathrm{sd}(z_1,z_2,\ldots,z_m)}{\mathrm{mean}(|z_1|,|z_2|,\ldots,|z_m|)}\]

A low CV indicates stability across baseline definitions. A high CV indicates substantial sensitivity.

Smoothing selection

15. FFT Selection Criteria

This tab helps select an FFT fraction \(f\). The application compares candidate fractions \(f=0.10,0.15,0.20,0.25,0.30,0.35,0.40\) using four descriptive criteria.

15.2. Grid assessment for candidate FFT fractions

ColumnMathematical definitionInterpretation
fFraction of retained low-frequency components.Lower \(f\) = stronger smoothing; higher \(f\) = weaker smoothing.
k_keep\(\max(1,\lfloor f n_{pos}\rfloor)\).Number of retained low-frequency components on the positive-frequency side.
corr_raw_smooth\(\mathrm{cor}(x,\hat{x})\).A value close to 1 indicates that the smoothed signal retains the overall shape of the raw trace.
retained_power_frac\(\frac{\sum_{k\in K_{kept}} |X_k|^2}{\sum_k |X_k|^2}\).Fraction of spectral energy retained. A low value indicates that substantial signal variation is being discarded.
n_peaksNumber of peaks detected using internal exploratory parameters.Evaluates whether smoothing changes the number of detected events.
mean_peakMean absolute amplitude of detected peaks.Used in Criterion 4 to select a candidate close to the weighted mean.
Note: this table uses fixed internal parameters to compare candidates consistently. It may not use all manually selected Find Peaks Function Arguments.

15.3. Criterion 1: Raw vs. FFT-smoothed signal

Each panel shows the same trace using a different FFT fraction \(f\). This criterion evaluates morphological preservation.

Visual patternInterpretation
The smoothed curve follows major peaks while reducing noise.Good candidate.
The smoothed curve is excessively flat and removes narrow events.\(f\) is likely too low.
The smoothed curve follows small noisy oscillations.\(f\) is likely too high.

15.4. Criterion 2: Residuals

Residuals are defined as:

\[r_t=x_t-\hat{x}_t\]

A suitable residual should resemble noise distributed around zero. If the shape of a calcium transient remains visible in the residual, FFT smoothing has removed biologically meaningful signal.

Residual patternWhat it indicates
Small, centered around zero, and without obvious structure.Appropriate smoothing.
Large waves with peak-like morphology.Over-smoothing; the reconstruction has removed events.
Very small residuals but a visibly noisy smoothed signal.Under-smoothing; \(f\) may be too high.

The application compares the residual standard deviation of each candidate against that of the reference candidate \(f=0.40\). Under the internal heuristic, a candidate passes this criterion when:

\[\mathrm{sd}(r_f) \le 1.5\,\mathrm{sd}(r_{0.40})\]

15.5. Criterion 3: Periodogram and cutoff

The periodogram measures power as a function of frequency:

\[I(\omega_k)=\frac{|X_k|^2}{n}, \qquad \omega_k=\frac{2\pi k}{n}\]

The vertical dashed line marks the approximate cutoff:

\[\omega_c=\frac{2\pi(k_{keep}-1)}{n}\]

The application considers retaining at least 90% of spectral power to be favorable:

\[\mathrm{retained\_power\_frac}\ge 0.90\]

15.6. Criterion 4: Mean peak closeness to weighted mean

This criterion compares each candidate's mean_peak value against a weighted mean, using the number of detected peaks as the weight:

\[\bar{p}_{w}=\frac{\sum_f n_f\,\mathrm{mean\_peak}_f}{\sum_f n_f}\]

The candidate recommended by this criterion is the one that minimizes:

\[\left|\mathrm{mean\_peak}_f-\bar{p}_{w}\right|\]

Interpretation: this criterion identifies an FFT fraction that does not systematically produce overly small peaks through over-smoothing or overly large/noisy peaks through under-smoothing. The final decision should integrate this result with visual inspection of Criteria 1–3.

Practical recommendation

Recommended Workflow

  1. Inspect the ROI in 12. SummaryData.
  2. Start with an FFT fraction between 0.20 and 0.30, and enable Raw Data.
  3. Adjust Find Peaks parameters until the detected peaks match visually apparent events.
  4. Compare baseline definitions in 14. Baseline Sensitivity Analysis.
  5. Use 15. FFT Selection Criteria to justify or refine the selected FFT fraction.
  6. Always report the baseline method, FFT fraction, and peak-filtering parameters used.
