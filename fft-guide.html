FFT tab

1. SummaryData

This tab summarizes the dataset and the selected ROI before event detection. It should help the user verify that the correct file and ROI are being analyzed.

  • Dataset Summary: number of observations, number of ROIs, and selected ROI.
  • Dataset: interactive table of the loaded data.
  • Selected ROI Trace: plot of the selected calcium signal over time.
  • Selected ROI Descriptive Summary: minimum, maximum, mean, median, standard deviation, and related summaries.

FFT tab

2. Peaks

This tab displays the detected calcium transients after FFT smoothing and peak detection. It is the main visual quality-control section for the FFT workflow.

  • Annotated calcium trace with detected peaks.
  • Optional raw trace overlay.
  • Baseline reference or dynamic baseline curve.
  • Peak-level annotations such as prominence, FWHP, FWHM, onset, and AUC when enabled.

FFT tab

4. Metric plots

This tab visualizes metrics grouped by family. Metrics with different units should not be interpreted on the same scale unless they are normalized or grouped appropriately.

  • Event detection metrics.
  • Time-domain metrics.
  • Signal amplitude metrics.
  • Area under the curve metrics.

FFT tab

5. Fourier analysis

This tab documents the FFT smoothing step. It helps users understand how the low-frequency fraction affects the reconstructed signal.

  • Smoothed fit and raw-versus-smoothed comparison.
  • Residual plot.
  • Frequency spectrum and retained frequency table.
  • Reconstruction information based on retained FFT components.

FFT tab

6. Baseline sensitivity analysis

This tab compares transient metrics across baseline definitions. It is essential for determining whether amplitude, AUC, and width-based conclusions are robust.

  • Baseline comparison table.
  • Metric plots across baseline definitions.
  • Automatic interpretation using coefficient of variation for amplitude, AUC, and FWHM.

FFT tab

7. FFT selection criteria

This tab evaluates candidate FFT low-frequency fractions. It helps users choose a smoothing level that balances noise reduction and morphology preservation.

1. Signal morphology

Checks whether smoothed signal preserves calcium transient shape.

2. Residual behavior

Assesses residual magnitude and structure.

3. Spectral power

Evaluates retained periodogram power.

4. Mean peak stability

Compares mean peak amplitude across candidate fractions.

Suggested FFT reporting sentence

Calcium transients were detected using the FFT + Baseline Analysis module in CalciumInsights. The selected ROI trace was smoothed using FFT low-pass reconstruction, peaks were identified using user-defined peak-detection parameters, and event metrics were calculated using the selected baseline definition. Baseline sensitivity was evaluated across multiple baseline definitions.
