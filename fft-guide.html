Purpose of the FFT module

The FFT module analyzes calcium transient traces using FFT low-pass smoothing, peak detection, baseline correction, AUC estimation, FWHM/FWHP metrics, optional sigmoid modeling, and exploratory tools for choosing the FFT smoothing fraction.

Important: The module is designed so that the denoising step is performed with FFT-based reconstruction. The downstream metrics are then computed from the selected ROI after smoothing and optional baseline correction.

1. Example Data

Use this option to decide whether the app should load a built-in simulated calcium dataset.

OptionMeaning
YesThe app uses the internal example dataset. This is useful for demonstrations, testing, and teaching.
NoThe app expects the user to upload an external dataset in section 2. Dataset.

2. Dataset

Upload the calcium trace dataset. The module accepts common text-based formats such as .csv, .tsv, and .json.

The first column should represent time. The remaining columns should represent ROIs or calcium traces.

Time,ROI_1,ROI_2,ROI_3
0.0,0.45,0.50,0.43
0.5,0.48,0.52,0.46
1.0,0.51,0.55,0.49
Make sure the time column is numeric and ordered. The ROI selected in section 3 is interpreted as a column index after the Time column.

3. Region of Interest (ROI)

Select the ROI to analyze. For example, ROI = 1 means the first signal column after the Time column.

The selected ROI is used for the FFT smoothing, peak detection, baseline estimation, AUC, FWHM/FWHP, sigmoid modeling, and all output tables.

4. FFT Low-Frequency Fraction

This parameter controls the fraction of low-frequency Fourier components retained during FFT-based smoothing.

ValueExpected effect
Lower values, e.g. 0.10Stronger smoothing; more high-frequency variation is removed.
Intermediate values, e.g. 0.20–0.30Balanced smoothing; often useful for preserving transient morphology while reducing noise.
Higher values, e.g. 0.40–1.00Less smoothing; more of the original trace is preserved.

4.1. Keep Mean (DC Component)

When selected, the global average level of the signal is preserved during FFT reconstruction. This is usually recommended because it keeps the reconstructed trace on the same fluorescence scale as the original signal.

5. Find Peaks Function Arguments

These parameters control how peaks/transients are detected after FFT smoothing.

5.1. Peak Height (min)

Minimum signal intensity required for a point to be considered a candidate peak.

5.2. Peak Ascent

Minimum number of increasing points before the peak. Larger values make the detector more restrictive.

5.3. Peak Descent

Minimum number of decreasing points after the peak. Larger values favor more clearly defined peaks.

5.4. Min Peak Distance

Minimum distance between consecutive peaks. This helps prevent detecting multiple nearby points from the same transient as separate peaks.

5.5. FWHP (min)

Minimum full width at half prominence required for a detected transient to be retained.

5.6. Prominence (min)

Minimum prominence required for a detected peak. This filters out weak or poorly separated peaks.

6. Baseline

The baseline defines the reference fluorescence level used for corrected amplitude, AUC, and other transient metrics. Because baseline choice can affect quantitative conclusions, the app includes several baseline definitions.

6.1. Standard Definition

Estimates a global baseline using the initial fraction of the trace.

6.1.1. Initial Trace Fraction

Defines the fraction of the beginning of the trace used for baseline estimation. For example, 0.10 uses the first 10% of the trace.

6.2. Low-Fluorescence Region Baseline

Estimates the baseline from the lowest fluorescence values in the trace.

6.2.1. Minimal Lower Fraction

Defines the fraction of the lowest signal values used to estimate the baseline.

6.3. Rolling Percentile Baseline

Computes a dynamic baseline using a moving time window and a selected percentile.

6.3.1. Moving Window Size

Controls the size of the moving window. Use the same time unit as the Time column.

6.3.2. Percentile

Controls the percentile used within each window. A low percentile, such as 2%, is often used to approximate the lower fluorescence envelope.

6.3.3. Show Fixed-Window Intervals on Calcium Trace

Displays fixed-window intervals on the calcium trace when applicable.

6.4. Event-Specific Baseline: Left-Right FFT Minima

Computes a local baseline for each detected event using local minima to the left and right of the peak. This is useful when the baseline varies across events.

6.5. Median Signal (Legacy)

Uses the median of the signal as the baseline.

6.6. Mean Signal (Legacy)

Uses the mean of the signal as the baseline.

6.7. Min

Uses the minimum value of the signal as the baseline.

7. Area Under the Curve (AUC)

Turns AUC calculation and visualization on or off. When activated, the app estimates the area above the selected baseline. AUC summarizes the total transient signal over time.

8. Raw Data

Controls whether the raw calcium trace is displayed together with the FFT-smoothed trace. Showing raw data is useful for checking whether smoothing preserves the important biological events.

9. Full Width at Half Maximum

Activates the calculation and visualization of full width at half maximum or related width metrics. This is useful for characterizing transient duration.

10. Optional Sigmoid Modeling

Optional sigmoid models add extra event-level metrics. They do not change the FFT smoothing, peak detection, baseline, AUC, FWHM, or FWHP workflow.

10.1. Apply Single Sigmoid Fit for Onset and Rise-Time Metrics

Fits a single sigmoid to estimate onset time, rise time, rise rate, and related model-based parameters.

10.2. Apply Double Sigmoid Fit for Full-Transient Metrics

Fits a double sigmoid to describe both rise and decay phases of the transient. This adds onset, offset, duration, decay time, rise slope, decay slope, and model-fit metrics.

10.3. Pre-Event Window for Baseline RMS

Defines the time window before the event used to estimate baseline noise through RMS.

10.4. Single Sigmoid Left Padding

Extends the fitting window to the left for the single sigmoid model.

10.5. Single Sigmoid Right Padding

Extends the fitting window to the right for the single sigmoid model.

10.6. Double Sigmoid Left Padding

Extends the fitting window to the left for the double sigmoid model.

10.7. Double Sigmoid Right Padding

Extends the fitting window to the right for the double sigmoid model.

This tab contains the main peak detection and FFT analysis results.

13.1. Metrics

Contains the metric tables generated by the analysis.

13.1.1. Trace Metrics Table

Summarizes trace-level metrics, such as number of detected peaks and average event properties.

Provides event-level metrics for each detected transient.

13.2.1. Calcium Trace with Detected Peaks

Main plot showing the calcium trace, detected peaks, baseline, AUC, FWHM/FWHP, and optional model overlays.

13.2.2. First Derivative Plot

Shows the derivative-based behavior of the selected trace.

13.2.3. Polynomial Trend Removal Plot

Displays the polynomial trend and detrended trace when trend removal is activated.

13.2.4. Fitted Polynomial Trend Information

Reports the fitted polynomial equation and model information.

13.2.5. Polynomial Coefficient Table

Displays coefficient estimates and statistical information for the fitted polynomial trend model.

13.3. Fourier Analysis

13.3.1. FFT Summary

Provides textual information about the FFT reconstruction, including retained frequencies.

13.3.2. FFT Fit Plot

Compares the original signal with the FFT-smoothed signal.

13.3.3. FFT Residual Plot

Shows residuals between the original and FFT-smoothed traces.

13.3.4. Spectrum Plot

Displays spectral power across frequencies.

13.3.5. Frequency Table

Lists frequency index, angular frequency, period, magnitude, power, and whether each frequency was retained.

13.3.6. Explicit Reconstruction Formula

Shows the finite sine-cosine expression used to reconstruct the smoothed trace from retained FFT components.

13.3.7. Theory and Interpretation

Explains how the FFT decomposes the calcium trace and why low-pass filtering can reduce noise.

14. Baseline Sensitivity Analysis

This tab compares calcium transient metrics across different baseline definitions.

14.1. Methodological Note: Why Baseline Matters

Explains why the selected baseline can affect amplitude, AUC, FWHM, and the number of accepted events.

14.2. Baseline Sensitivity Table

Displays the metrics calculated under different baseline methods.

14.3. Baseline Sensitivity Plot

Visualizes how the metrics change across baseline definitions.

14.4. Baseline Sensitivity Interpretation

Provides an automatic interpretation of whether the analysis is relatively robust or sensitive to baseline choice.

15. FFT Selection Criteria

This tab helps evaluate which FFT low-frequency fraction may be appropriate for the selected trace.

15.1. Selection of FFT Low-Frequency Fraction

The app evaluates candidate fractions f = 0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40.

15.2. FFT Candidate Summary Table

Summarizes candidate-specific metrics for each tested FFT fraction.

15.3. Criterion 1: Signal Morphology Preservation

Assesses whether the smoothed signal preserves the important shape of the original calcium trace.

15.4. Criterion 2: Residual Structure and Magnitude

Evaluates the residual signal after FFT smoothing. A good smoothing setting should remove noise without leaving strong structured biological signal in the residuals.

15.5. Criterion 3: Retained Spectral Power Fraction

Reports how much spectral power is retained by each candidate fraction.

15.6. Criterion 4: Mean Peak Agreement

Compares each candidate mean peak amplitude to a weighted reference mean computed across candidate fractions.

15.7. FFT Selection Metrics Plot

Displays the candidate metrics visually to support final selection of the FFT fraction.

The app can recommend a candidate fraction, but the final decision should consider the trace morphology, biological plausibility, and research objective.

Recommended Workflow

  1. Start with 1. Example Data or upload your file in 2. Dataset.
  2. Select the calcium trace in 3. Region of Interest (ROI).
  3. Inspect the trace in 12. SummaryData.
  4. Choose an initial 4. FFT Low-Frequency Fraction, such as 0.20.
  5. Adjust 5. Find Peaks Function Arguments until the detected events match the visible transients.
  6. Select an appropriate 6. Baseline method.
  7. Use 13. Peaks to inspect detected transients and metrics.
  8. Use 14. Baseline Sensitivity Analysis to check whether conclusions depend strongly on the baseline method.
  9. Use 15. FFT Selection Criteria to compare candidate FFT fractions.
  10. Export results using 11. Download Options.
