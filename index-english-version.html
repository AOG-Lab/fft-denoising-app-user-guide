Purpose

1. Overview

CalciumInsights analyzes calcium signals for each region of interest, or ROI. The application enables users to upload a time-by-signal matrix, select an ROI, detect events, estimate the baseline, and calculate metrics including amplitude, prominence, width, frequency, area under the curve, and rise times.

This documentation follows the numbering displayed in the application. When a user encounters an output such as Baseline Sensitivity Analysis, Grid assessment for candidate FFT fractions, Event-Level Metrics, or Wavelet Analysis, they can navigate to the corresponding section to understand what is shown and how to interpret it.

Core concept: calcium metrics depend on methodological decisions. The application therefore compares baseline definitions, FFT fractions, and wavelet-based detections to help distinguish robust conclusions from conclusions that are sensitive to the selected method.

Shared mathematical language

2. Common notation

Signal and baseline

We use:

\[x_i = x(t_i) \quad \text{observed signal at time } t_i\]

\[\hat{x}_i = \hat{x}(t_i) \quad \text{smoothed or reconstructed signal}\]

\[b_i = b(t_i) \quad \text{static, dynamic, or local baseline}\]

Core metrics

\[A_i = x(t_{p,i}) - b(t_{p,i})\]

Amplitude above baseline at the peak of event \(i\).

\[\Delta F/F_0 = \frac{x(t_{p,i}) - b(t_{p,i})}{b(t_{p,i})}\]

Relative fluorescence change. In the application, the Baseline term serves as \(F_0\).

Shared terminology

4. Shared baselines

Both modules use equivalent baseline labels so that FFT- and Wavelet-derived metrics can be compared consistently.

BaselineConceptWhen it is useful
Standard definitionMean of an initial fraction of the signal.Recordings in which the beginning of the trace represents the resting state.
Low-fluorescence region baselineBaseline estimated from low fluorescence values.Signals with frequent events but identifiable low-fluorescence intervals.
Rolling percentile baselineDynamic baseline calculated using a moving window and percentile.Long recordings with slow baseline drift.
Event-specific baseline: left-right FFT minimaLocal baseline defined between minima before and after the peak.Events with a variable local baseline.
Median signal (legacy)Median of the full signal.Retrospective comparison or rapid exploratory analysis.
Mean signal (legacy)Mean of the full signal.Retrospective comparison; sensitive to large peaks.
MinObserved minimum.Simple lower reference; may overestimate amplitudes when downward noise is present.

How to read these examples:

The black curve represents the FFT-smoothed calcium signal. The green dashed curve or line represents the selected baseline. Colored overlays mark the specific quantity being measured, such as onset, peak time, amplitude, AUC, width, rise rate, or sigmoid-derived decay metrics.
