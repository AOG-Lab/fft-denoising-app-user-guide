Purpose

1. Overview

CalciumInsights is an interactive Shiny application for analyzing calcium transient traces from one or more regions of interest. The documentation is divided into module-specific pages so users can follow the same order that appears in the app interface.

Important: the guide numbering should match the visible numbering inside the Shiny modules. This makes the app easier to teach, review, and reproduce.

Consistency

3. Numbering logic

1. Inputs first

Controls in the left panel are numbered before output tabs. This follows how users configure the analysis.

2. Outputs second

Result tabs are numbered after the inputs. This follows how users interpret the results after running the module.

3. Same names everywhere

The same labels should appear in the Shiny app, guide pages, README, and screenshots.

Shared terminology

4. Shared baseline names

Both modules should use the same baseline terminology so users can compare FFT-derived and wavelet-derived metrics without confusion.

Baseline optionPurpose
Standard definitionBaseline estimated from an initial fraction of the selected calcium trace.
Low-fluorescence region baselineBaseline estimated from the lowest fluorescence values in the selected trace.
Rolling percentile baselineDynamic moving-window percentile baseline for drifting or long-duration recordings.
Event-specific baseline: left-right FFT minimaLocal baseline estimated from minima surrounding each detected transient.
Median signal (legacy)Legacy option that uses the median of the selected signal.
Mean signal (legacy)Legacy option that uses the mean of the selected signal.
MinUses the minimum observed signal as the baseline.
