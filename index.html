Purpose

1. Overview

CalciumInsights is an interactive Shiny application for analyzing calcium transient traces from one or more regions of interest. The app includes two complementary workflows: an FFT-based peak-detection workflow and a wavelet ridgewalking workflow.

The purpose of this guide is to help users follow the same section names and numbering used in the app. For example, when this guide refers to 1. SummaryData, the corresponding tab in the app should also appear as 1. SummaryData in the relevant module.

What the app does

  • Loads example data or user-provided CSV, TSV, or JSON files.
  • Selects a single ROI trace for detailed inspection.
  • Detects calcium events using FFT/findpeaks or wavelet ridgewalking.
  • Applies consistent baseline definitions across both modules.
  • Reports event-level and trace-level metrics.
  • Evaluates baseline sensitivity before biological interpretation.
  • Exports tables and annotated figures.

Scope

2. Intended use

CalciumInsights is intended for calcium fluorescence time series extracted from microscopy or calcium imaging pipelines. It is useful for exploratory analysis, teaching, parameter tuning, reproducible reporting, and comparing whether conclusions are stable across detection approaches.

Important: The app is an analytical and visualization tool. Final biological interpretation should consider experimental design, acquisition frequency, signal quality, cell type, stimulation protocol, and the appropriateness of selected detection and baseline settings.

Basic operation

4. Quick start

  1. Choose the data source. Use example data or upload a CSV, TSV, or JSON file.
  2. Select the ROI. Choose the region of interest to analyze.
  3. Choose the analysis module. Use either FFT + Baseline Analysis or Wavelet Ridgewalking.
  4. Set method-specific parameters. Adjust peak-detection or ridgewalking settings.
  5. Select a baseline method. Use the same baseline names across both modules.
  6. Inspect outputs using the numbered tabs. Follow the section number in the app and the guide.
  7. Evaluate baseline sensitivity. Check whether amplitude, AUC, or width conclusions change across baseline definitions.
  8. Export results. Download tables and annotated calcium trace figures.

Application structure

5. Main modules

FFT + Baseline Analysis

Peak-based workflow for smoothing calcium traces, detecting local maxima, applying baseline definitions, and extracting transient metrics.

  • FFT low-pass smoothing.
  • Peak detection using user-defined arguments.
  • Baseline sensitivity analysis.
  • Fourier analysis and FFT selection criteria.

Wavelet Ridgewalking

Multiscale event-detection workflow for identifying calcium events as ridge-like structures in a wavelet transform representation.

  • Continuous wavelet transform map.
  • Ridge-based event detection.
  • Biological post-filtering.
  • Wavelet-derived metrics and baseline sensitivity.
Numbering rule used in this guide: Every tab name in the guide should match the visible tab name in the corresponding app module.

Robustness

9. Baseline sensitivity analysis

Baseline sensitivity analysis compares metrics across baseline definitions. This is important because amplitude, AUC, FWHM, FWHP, and some event-acceptance decisions can change depending on the selected baseline.

Amplitude sensitivity

Evaluates whether amplitude-based conclusions depend on baseline choice.

AUC sensitivity

Evaluates whether integrated calcium activity changes across baseline definitions.

Width sensitivity

Evaluates whether FWHM or related duration metrics are affected by baseline choice.

Interpretation: If values are similar across baseline methods, the result is more robust. If values change strongly, report the result as baseline-sensitive.

Support

12. Troubleshooting

Reduce peak thresholds, reduce ridge strictness, check whether smoothing is too strong, and verify that the selected ROI contains visible calcium activity.

Increase peak height, minimum distance, prominence, ridge length, or CWT amplitude quantile. Also review whether the trace contains high-frequency noise.

Report amplitude and AUC conclusions with caution. Timing and frequency metrics may be more stable than amplitude-based metrics.

Confirm that the first column is time, all ROI columns are numeric, and the file format is CSV, TSV, or JSON.

Questions

13. FAQ

Why are the app tabs numbered?

Numbering makes the user guide and the Shiny interface match exactly, making it easier to teach, review, and reproduce analyses.

Why are there two detection modules?

FFT-based peak detection is intuitive for clear peaks, while wavelet ridgewalking can detect broader or multiscale events.

Which baseline should I use?

Use the standard definition for stable initial resting fluorescence, rolling percentile baseline for drifting traces, and event-specific baseline for local event references.

How should I report the analysis?

Report the module, numbered section, ROI, parameter settings, baseline method, sensitivity analysis, and exported metrics.

Suggested methods description

Calcium transient traces were analyzed using CalciumInsights, an interactive Shiny application with FFT + Baseline Analysis and Wavelet Ridgewalking modules. For each selected ROI, events were detected using method-specific parameters. Metrics included event frequency, amplitude above baseline, peak timing, onset, rise time, FWHM/FWHP, prominence, wavelet-derived metrics, and area under the curve. Baseline sensitivity was evaluated across standard, low-fluorescence, rolling percentile, event-specific, median, mean, and minimum baselines.
