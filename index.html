Purpose

1. Overview

CalciumInsights is an interactive Shiny application for analyzing calcium transient traces from one or more regions of interest. The app includes two complementary workflows: an FFT-based workflow and a wavelet ridgewalking workflow.

This home page now follows the same documentation style as fft-guide.html and wavelet-guide.html: a large header, a left table of contents, numbered sections, cards, tables, and a clear workflow for users.

Consistency rule: the numbers shown in the guide should match the numbers shown inside the Shiny modules. This helps users move between the app and the documentation without confusion.

Consistency

5. Shared baseline names

Both modules should use the same visible baseline names. This allows users to compare FFT-derived and wavelet-derived metrics using the same conceptual baseline definitions.

Baseline optionPurpose
Standard definitionBaseline estimated from an initial fraction of the selected calcium trace.
Low-fluorescence region baselineBaseline estimated from the lower fluorescence values of the trace.
Rolling percentile baselineDynamic moving-window percentile baseline for drifting or long-term traces.
Event-specific baseline: left-right FFT minimaLocal baseline estimated from minima surrounding each detected transient.
Median signal (legacy)Legacy option that uses the median of the selected signal.
Mean signal (legacy)Legacy option that uses the mean of the selected signal.
MinUses the minimum observed signal as the baseline.

Publishing

6. Recommended update workflow

  1. Replace the website files in the GitHub repository root.
  2. Keep index.html, fft-guide.html, wavelet-guide.html, style.css, script.js, and README.md together.
  3. Confirm that the navigation links open the two module guides.
  4. Commit and push the changes so GitHub Pages updates the public website.
