Purpose

1. Overview

CalciumInsights is an interactive Shiny application for analyzing calcium transient traces from one or more regions of interest. The app includes two complementary workflows: an FFT-based peak-detection workflow and a wavelet ridgewalking workflow.

This website is organized so that each module has its own guide page. Each guide uses the same visible numbering used inside the Shiny app. For example, when the FFT guide says 1. SummaryData, the FFT module tab should also say 1. SummaryData.

Guide structure

  • Home page: general purpose and app structure.
  • FFT guide page: numbered tabs and controls for FFT + Baseline Analysis.
  • Wavelet guide page: numbered tabs and controls for Wavelet Ridgewalking.
  • Consistent baseline names across both modules.
