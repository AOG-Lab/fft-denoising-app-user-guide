Wavelet Ridgewalking — Detailed Results Guide

This page explains how the module detects calcium events as multiscale structures, how to interpret ridges in the CWT map, and the meaning of each metric shown in the tables, plots, and baseline sensitivity analysis.

Method overview

Purpose of the Wavelet Ridgewalking Module

The Wavelet Ridgewalking module detects calcium transients using a time-scale representation. Rather than searching only for maxima in a smoothed signal, it calculates an approximation of the continuous wavelet transform, identifies local maxima in wavelet amplitude, and connects these maxima across scales to form ridges.

After candidate events are detected, the module calculates biologically relevant metrics, including amplitude above baseline, \(\Delta F/F_0\), prominence, FWHM, FWHP, rise time, event AUC, global AUC, ridge length, CWT amplitude, mean scale, and event status.

Key difference from FFT: wavelet detection occurs before baseline correction is applied. The baseline is used afterward to quantify the detected events. Therefore, the Baseline Sensitivity Analysis tab evaluates changes in post-detection metrics rather than changes in the original ridge structure.

Mathematical concepts

0. Wavelet notation

Ricker / Mexican hat wavelet

The module uses a real-valued Ricker-like approximation:

\[\psi(u)=(1-u^2)e^{-u^2/2}\]

This shape responds strongly to peak-like events with a rise, maximum, and decay phase.

CWT amplitude

For scale \(s\) and central time \(\tau\):

\[W(s,\tau)\approx \sum_i z(t_i)\frac{1}{\sqrt{s}}\psi\left(\frac{t_i-\tau}{s}\right)\Delta t\]

The application uses the amplitude:

\[\mathrm{CWT\ amplitude}=|W(s,\tau)|\]

Scale: a small scale detects narrow, rapid events, whereas a large scale detects broader or slower events. A biologically plausible event generally appears as a coherent structure across multiple scales.

1. Example Data

Allows the use of internally generated simulated data to test the module without uploading a file. This is useful for learning how ridgewalking outputs appear before analyzing experimental data.

2. Dataset

The input file must contain a time column as the first column, followed by one or more ROI columns. Accepted formats are .csv, .tsv, and .json.

3. Region of Interest (ROI)

Selects the signal to be analyzed. The selected ROI is used for the CWT calculation, ridge construction, event metrics, AUC calculations, baseline estimation, and all plots.

4. Wavelet Ridgewalking Function Arguments

These parameters control multiscale event detection before biological filters are applied.

Conceptual algorithm

  1. Calculate CWT amplitude \(|W(s,\tau)|\) across multiple scales.
  2. Identify local maxima at each scale that exceed a quantile threshold.
  3. Connect nearby maxima across adjacent scales when \(|\tau_s-\tau_{s-1}|\le \epsilon\).
  4. Retain ridges with sufficient length.
  5. Merge events that are too close together.
ControlDefinitionEffect of increasing the value
4.1. Minimum ScaleMinimum scale included in the analysis.May exclude very narrow events if increased excessively.
4.2. Maximum ScaleMaximum scale included in the analysis.Allows detection of broader events but may merge slow trends with events.
4.3. Number of ScalesNumber of scales evaluated between the minimum and maximum scale.Provides higher multiscale resolution at greater computational cost.
4.4. CWT Amplitude QuantileQuantile used as a threshold for local maxima.Makes detection more selective by retaining only stronger wavelet structures.
4.5. Ridge Connection ToleranceTemporal tolerance \(\epsilon\) for connecting maxima across scales.Allows ridges to connect despite small time shifts; if too large, it may join distinct structures.
4.6. Min Ridge LengthMinimum number of connected scales.Requires stronger multiscale coherence and reduces noise-driven detections.
4.7. Min Event DistanceMinimum distance between detected events.Merges nearby events and helps prevent duplicate detections.
4.8. Metric Window Around EventLocal time window used to refine onset, peak, offset, and AUC.Larger windows can capture longer events but may include neighboring events.

5. Baseline

In this module, the baseline is applied after wavelet events are detected. It affects amplitude, \(\Delta F/F_0\), FWHM, FWHP, AUC, and amplitude-based event classification.

5.1. Standard definition

Mean of the initial fraction of the trace. Mathematically: \(b=\frac{1}{m}\sum_{i=1}^{m}x_i\).

5.2. Low-fluorescence region baseline

Uses low fluorescence values to approximate the resting state. Useful when the beginning of the trace is not representative of baseline activity.

5.3. Rolling percentile baseline

Calculates a dynamic baseline \(b(t)\) using a moving window and a selected percentile.

5.4. Event-specific baseline: left-right FFT minima

For each detected wavelet peak, identifies FFT-smoothed minima on the left and right. The line between these minima defines the local baseline for that event.

5.5–5.7. Median / Mean / Min

Legacy options and global minimum references. Useful for comparison, but less adaptive to local changes in the trace.

Amplitude Above Baseline

\[\text{Amplitude Above Baseline}_j = x(t_{p,j})-b_j\]

For an event-specific baseline, \(b_j\) is the value of the local baseline line at the event peak time.

Baseline robustness

10. Baseline Sensitivity Analysis

This tab retains the same wavelet candidates and recalculates metrics using multiple baseline definitions. It therefore evaluates whether biological interpretation depends on the selected baseline.

Coefficient of variation used for automatic interpretation

\[CV(\%)=100\cdot\frac{\mathrm{sd}(z_1,z_2,\ldots,z_m)}{\mathrm{mean}(|z_1|,|z_2|,\ldots,|z_m|)}\]

The application applies this principle primarily to amplitude, AUC, and FWHM because these metrics are typically sensitive to baseline selection.

13. Wavelet Analysis

The Wavelet Analysis tab displays a CWT amplitude map. The x-axis represents time, the y-axis represents scale, and color represents \(|W(s,\tau)|\). Points indicate local maxima used as candidates for ridge construction.

ElementWhat it meansInterpretation
X-axis: TimeRecording time.Indicates when an event occurs.
Y-axis: ScaleTemporal width of the wavelet.Small scales respond to narrow events; large scales respond to broad events.
Color / Fill: CWT amplitude\(|W(s,\tau)|\).Bright regions indicate event-like structure.
Local-maxima pointsScale-specific maxima exceeding the quantile threshold.These are the nodes connected to form ridges.
Implicit ridgesSequences of connected maxima.A long, strong ridge suggests a more reliable event.
Warning sign: if the CWT map shows many scattered small structures without continuity across scales, increase the CWT quantile threshold, increase the minimum ridge length, or inspect the trace for excessive noise.

Practical recommendation

Recommended Workflow

  1. Inspect the selected ROI in 8. SummaryData.
  2. Begin with a broad scale range, for example minimum scale 2 and maximum scale 40.
  3. Inspect 13. Wavelet Analysis to confirm that visually apparent events correspond to strong CWT structures.
  4. Adjust CWT Amplitude Quantile, Ridge Connection Tolerance, and Min Ridge Length.
  5. Use 6. Biological Event Filters to classify candidate events.
  6. Review 10. Baseline Sensitivity Analysis before reporting amplitude, AUC, or FWHM.
  7. Always report the minimum and maximum scales, number of scales, CWT quantile, minimum ridge length, baseline method, and included event classes.
