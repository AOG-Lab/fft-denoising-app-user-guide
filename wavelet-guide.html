Overview

The Wavelet Ridgewalking module detects calcium transient candidates using a multiscale wavelet representation. The module first identifies local maxima in the continuous wavelet transform map, connects them across scales as ridges, merges close candidates, and then computes biological metrics such as peak amplitude, baseline-corrected amplitude, prominence, FWHP, FWHM, rise time, event AUC, global AUC, ridge length, CWT amplitude, and event status.

Important: wavelet ridgewalking is used for event detection, while the selected baseline method is applied afterward to calculate post-detection metrics. This is why the module includes a dedicated baseline sensitivity analysis.

1. Example Data

Use this option to decide whether the app should load the built-in simulated calcium dataset. Select Yes when teaching, testing, or demonstrating the module without uploading a file. Select No when analyzing your own dataset.

2. Dataset

Upload an external file containing time-series calcium traces. The module accepts common tabular formats such as .csv, .tsv, and .json.

Recommended structure: the first column should represent time, and the following columns should represent individual ROIs.

3. Region of Interest (ROI)

Select the ROI column to analyze. The selected ROI is used for wavelet detection, baseline estimation, event metrics, AUC calculations, and all plots in this module.

4. Wavelet Ridgewalking Function Arguments

These parameters control the multiscale wavelet detection step. They affect how candidate events are detected before biological filtering and baseline-based metric calculation.

4.1. Minimum Scale

Smallest wavelet scale used in the CWT approximation. Smaller scales are more sensitive to narrow and fast events.

4.2. Maximum Scale

Largest wavelet scale used in the CWT approximation. Larger scales help detect broader events.

4.3. Number of Scales

Number of scales evaluated between the minimum and maximum scale. Increasing this value gives finer multiscale resolution.

4.4. CWT Amplitude Quantile

Threshold used to keep strong local maxima in the wavelet amplitude map. Higher values make detection more selective; lower values allow more candidates.

4.5. Ridge Connection Tolerance

Maximum time difference allowed when connecting maxima across adjacent scales. This parameter controls how strict the ridge construction step is.

4.6. Min Ridge Length

Minimum number of connected scale-level maxima required for a ridge to be considered a candidate event.

4.7. Min Event Distance

Minimum distance between detected events. Close candidates are merged, keeping the stronger event candidate.

4.8. Metric Window Around Event

Local time window around each wavelet-detected event used to refine onset, peak, offset, amplitude, rise time, and event AUC.

5. Baseline

The baseline determines how post-detection metrics are calculated. In this module, wavelet detection happens first; then the selected baseline is used to estimate quantities such as amplitude above baseline, DeltaF/F0, FWHM, FWHP, and AUC.

5.1. Standard definition

Uses the initial part of the trace to estimate a global scalar baseline.

5.1.1. Initial Trace Fraction

Fraction of the beginning of the trace used to calculate the mean baseline.

5.2. Low-fluorescence region baseline

Uses the lowest fluorescence values in the trace to estimate baseline.

5.2.1. Minimal Lower Fraction

Fraction of lowest values used to calculate the low-fluorescence baseline.

5.3. Rolling percentile baseline

Creates a time-varying baseline using a rolling window and percentile.

5.3.1. Rolling Baseline Window Points

Number of points included in the moving window.

5.3.2. Rolling Baseline Percentile

Percentile used within each rolling window.

5.4. Event-specific baseline: left-right FFT minima

For each transient, the baseline is estimated from the FFT-smoothed minimum before the peak and the FFT-smoothed minimum after the peak. A local line between these two values is used to estimate the baseline at the peak and across the event.

5.4.1. FFT Smoothing Fraction for Event-Specific Baseline

Controls the FFT smoothing used only for finding the left and right local minima used by the event-specific baseline.

5.4.2. Fallback Pre-Event Window

Window used to estimate a local fallback baseline if the event-specific left/right minima cannot be reliably defined.

5.4.3. Fallback Baseline Statistic

Statistic used in the fallback window, such as the median or 10th percentile.

5.5. Median signal (legacy)

Uses the median of the full signal as a static baseline.

5.6. Mean signal (legacy)

Uses the mean of the full signal as a static baseline.

5.7. Min

Uses the minimum signal value as the static baseline.

6. Biological Event Filters

These filters classify detected candidates as accepted, low confidence, or rejected based on biological and signal-quality criteria.

6.1. Amplitude Above Baseline (min)

Minimum baseline-corrected amplitude required for an event to be considered reliable.

6.2. Ridge Length for Accepted Status

Minimum ridge length required for an event to be classified as accepted.

6.3. CWT Amplitude (min)

Minimum wavelet coefficient amplitude required for an event to be considered strong enough.

6.4. Events Used in Summary Metrics

Defines which event classes are included in summary tables: accepted events only, accepted plus low-confidence events, or all candidates.

7. Graph Display Options

7.1. Full Width at Half Prominence (FWHP)

Displays or hides FWHP annotations in the event plot.

7.2. Show non-accepted event lines

Controls whether rejected or low-confidence event lines are shown in the detected-events plot.

8. SummaryData

8.1. Dataset Summary

Displays general information about the uploaded or simulated dataset.

8.2. Dataset

Shows the complete dataset in an interactive table.

8.3. Selected ROI Trace

Plots the calcium trace for the selected ROI.

8.4. Selected ROI Descriptive Summary

Provides descriptive statistics for the selected ROI.

9. Peaks

This tab contains the main wavelet event plot and event-level tables.

9.1. AUC Summary

Summarizes global AUC above baseline, total event AUC, mean event AUC, and related event-area statistics.

9.2. Event-Level Metrics

Provides one row per detected event, including onset time, peak time, offset time, amplitude, baseline, DeltaF/F0, prominence, FWHP, FWHM, rise time, rise rate, event AUC, ridge length, CWT amplitude, scale information, and event status.

10. Baseline Sensitivity Analysis

10.1. Methodological Note: Why Baseline Matters

This panel recomputes wavelet-derived metrics using the same detected ridge candidates under several baseline definitions. It helps determine whether the biological interpretation is stable or sensitive to baseline selection.

OutputPurpose
Baseline sensitivity tableCompares metrics across baseline methods.
Baseline sensitivity plotVisualizes how key metrics change with baseline definition.
InterpretationProvides a narrative summary of whether results are robust or baseline-sensitive.

11. Metrics

11.1. Summary Metrics

Aggregated metrics for the selected ROI and selected event set.

11.2. Transient Metrics

FFT-style transient metrics adapted to the wavelet-detected events.

11.3. Trace Metrics

Trace-level metrics such as time onset, frequency, baseline method, number of peaks, global AUC, and total event AUC.

12. Metric Plots

Displays graphical summaries of the main wavelet-derived metrics. Use this tab to visually evaluate distributions, event status patterns, and metric behavior across detected events.

13. Wavelet Analysis

Displays the continuous wavelet transform amplitude map. This plot helps verify whether detected events correspond to strong multiscale structures in the signal.

Recommended workflow

  1. Start with 1. Example Data or upload your own file in 2. Dataset.
  2. Select the target signal in 3. Region of Interest (ROI).
  3. Adjust 4. Wavelet Ridgewalking Function Arguments to control multiscale event detection.
  4. Select an appropriate 5. Baseline method for your biological question.
  5. Use 6. Biological Event Filters to classify reliable events.
  6. Inspect results in 8. SummaryData, 9. Peaks, and 13. Wavelet Analysis.
  7. Use 10. Baseline Sensitivity Analysis before reporting final biological conclusions.
