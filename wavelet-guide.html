Idea del método

Propósito del módulo Wavelet Ridgewalking

El módulo Wavelet Ridgewalking detecta transitorios de calcio usando una representación tiempo-escala. En lugar de buscar únicamente máximos en una señal suavizada, calcula una aproximación de la transformada wavelet continua, identifica máximos locales de amplitud wavelet y conecta esos máximos entre escalas para formar ridges.

Después de detectar candidatos, el módulo calcula métricas biológicas: amplitud sobre baseline, \(\Delta F/F_0\), prominencia, FWHM, FWHP, rise time, event AUC, global AUC, ridge length, CWT amplitude, escala media y estado del evento.

Diferencia clave con FFT: la detección wavelet ocurre antes de aplicar baseline. El baseline se usa después para cuantificar los eventos detectados. Por eso la pestaña Baseline Sensitivity Analysis evalúa cómo cambian las métricas post-detección, no la estructura de ridges original.

Conceptos matemáticos

0. Notación wavelet

Wavelet Ricker / Mexican hat

El módulo usa una aproximación real tipo Ricker:

\[\psi(u)=(1-u^2)e^{-u^2/2}\]

Esta forma responde fuertemente a eventos tipo pico: subida, máximo y bajada.

CWT amplitude

Para escala \(s\) y tiempo central \(\tau\):

\[W(s,\tau)\approx \sum_i z(t_i)\frac{1}{\sqrt{s}}\psi\left(\frac{t_i-\tau}{s}\right)\Delta t\]

La app usa la amplitud:

\[\mathrm{CWT\ amplitude}=|W(s,\tau)|\]

Escala: una escala pequeña detecta eventos estrechos y rápidos; una escala grande detecta eventos más anchos o lentos. Un evento biológicamente plausible suele aparecer como una estructura coherente en varias escalas.

1. Example Data

Permite usar datos simulados internos para probar el módulo sin subir archivo. Es útil para aprender cómo se ven las salidas de ridgewalking antes de analizar datos reales.

2. Dataset

El archivo debe tener una primera columna de tiempo y luego una o más columnas de ROI. Se aceptan formatos .csv, .tsv y .json.

3. Region of Interest (ROI)

Selecciona la señal que se analizará. La ROI seleccionada se usa para el CWT, los ridges, las métricas, AUC, baseline y todas las gráficas.

4. Wavelet Ridgewalking Function Arguments

Estos parámetros controlan la detección multiescala antes de aplicar los filtros biológicos.

Algoritmo conceptual

  1. Calcular amplitud CWT \(|W(s,\tau)|\) para varias escalas.
  2. Encontrar máximos locales en cada escala que superan un cuantile.
  3. Conectar máximos cercanos entre escalas vecinas si \(|\tau_s-\tau_{s-1}|\le \epsilon\).
  4. Conservar ridges con longitud suficiente.
  5. Fusionar eventos demasiado cercanos.
ControlDefiniciónEfecto al aumentarlo
4.1. Minimum ScaleEscala mínima analizada.Puede ignorar eventos muy estrechos si se aumenta demasiado.
4.2. Maximum ScaleEscala máxima analizada.Permite detectar eventos más anchos, pero puede mezclar tendencias lentas.
4.3. Number of ScalesNúmero de escalas entre mínimo y máximo.Mayor resolución multiescala, con más costo computacional.
4.4. CWT Amplitude QuantileCuantil usado como umbral para máximos locales.Más selectivo; conserva solo estructuras wavelet fuertes.
4.5. Ridge Connection ToleranceTolerancia temporal \(\epsilon\) para conectar máximos entre escalas.Conecta ridges aunque cambien ligeramente de tiempo; si es muy alto puede unir estructuras distintas.
4.6. Min Ridge LengthNúmero mínimo de escalas conectadas.Exige eventos más coherentes en escala; reduce ruido.
4.7. Min Event DistanceDistancia mínima entre eventos detectados.Fusiona eventos cercanos y evita duplicados.

5. Baseline

En este módulo, baseline se aplica después de detectar eventos wavelet. Afecta amplitud, \(\Delta F/F_0\), FWHM, FWHP, AUC y clasificación por amplitud.

5.1. Standard definition

Promedio de la fracción inicial del trazo. Matemáticamente: \(b=\frac{1}{m}\sum_{i=1}^{m}x_i\).

5.2. Low-fluorescence region baseline

Usa valores bajos de fluorescencia para aproximar reposo. Útil cuando el inicio no es representativo.

5.3. Rolling percentile baseline

Calcula un baseline dinámico \(b(t)\) usando una ventana en puntos y un percentil.

5.4. Event-specific baseline: left-right FFT minima

Para cada pico wavelet detectado, encuentra mínimos FFT suavizados a la izquierda y derecha. La línea entre esos mínimos define el baseline local del evento.

5.5–5.7. Median / Mean / Min

Opciones legacy y referencia mínima global. Útiles para comparación, pero menos adaptativas.

Amplitude Above Baseline

\[\text{Amplitude Above Baseline}_j = x(t_{p,j})-b_j\]

Si el baseline es event-specific, \(b_j\) es el valor de la línea local en el tiempo del pico.

Robustez frente a baseline

10. Baseline Sensitivity Analysis

Esta pestaña mantiene los mismos candidatos wavelet y recalcula métricas bajo varias definiciones de baseline. Así se evalúa si la interpretación biológica depende del baseline.

Coeficiente de variación usado en la interpretación automática

\[CV(\%)=100\cdot\frac{\mathrm{sd}(z_1,z_2,\ldots,z_m)}{\mathrm{mean}(|z_1|,|z_2|,\ldots,|z_m|)}\]

La app aplica esta idea principalmente a amplitud, AUC y FWHM, porque son métricas típicamente baseline-sensibles.

13. Wavelet Analysis

La pestaña Wavelet Analysis muestra un mapa de amplitud CWT. El eje x es tiempo, el eje y es escala y el color representa \(|W(s,\tau)|\). Los puntos señalan máximos locales usados como candidatos para formar ridges.

ElementoQué significaInterpretación
Eje X: TimeTiempo de grabación.Ubica cuándo ocurre un evento.
Eje Y: ScaleAncho temporal de la wavelet.Escalas pequeñas responden a eventos estrechos; grandes a eventos anchos.
Color / Fill: CWT amplitude\(|W(s,\tau)|\).Regiones brillantes indican estructura tipo evento.
Puntos de máximos localesMáximos por escala que superan el umbral de cuantile.Son los nodos que se conectan para formar ridges.
Ridges implícitosSecuencias de máximos conectados.Un ridge largo y fuerte sugiere evento más confiable.
Señal de alerta: si el mapa CWT muestra muchas estructuras pequeñas dispersas sin continuidad entre escalas, aumente el cuantile CWT, el mínimo ridge length o revise ruido en la señal.

Recomendación práctica

Workflow recomendado

  1. Revise la ROI en 8. SummaryData.
  2. Comience con escalas amplias, por ejemplo minimum scale 2 y maximum scale 40.
  3. Inspeccione 13. Wavelet Analysis para confirmar que los eventos visibles coinciden con estructuras CWT fuertes.
  4. Ajuste CWT Amplitude Quantile, Ridge Connection Tolerance y Min Ridge Length.
  5. Use 6. Biological Event Filters para clasificar eventos.
  6. Revise 10. Baseline Sensitivity Analysis antes de reportar amplitud, AUC o FWHM.
  7. Reporte siempre escala mínima/máxima, número de escalas, cuantile CWT, min ridge length, baseline y eventos incluidos.
