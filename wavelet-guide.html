Wavelet tab

1. SummaryData

This tab summarizes the dataset and selected ROI before wavelet ridgewalking. It should match the SummaryData structure used in the FFT module.

  • Dataset Summary: observations, ROIs, and selected ROI.
  • Dataset: interactive table of loaded data.
  • Selected ROI Trace: time-series plot of the selected calcium signal.
  • Selected ROI Descriptive Summary: basic descriptive statistics.

Wavelet tab

2. Peaks

This tab shows wavelet-detected calcium events. In this module, events are detected as ridge-like structures across scales rather than only as local maxima in the smoothed trace.

  • Accepted, low-confidence, or rejected event status.
  • Annotated calcium trace with wavelet-detected events.
  • Event-level metrics such as onset, peak time, amplitude, AUC, and wavelet-specific descriptors.
  • Optional biological post-filtering based on event criteria.

Wavelet tab

3. Baseline sensitivity analysis

This tab compares wavelet-derived metrics across baseline definitions. Wavelet detection itself is based on time-scale structure, but post-detection metrics such as amplitude and AUC still depend on baseline.

  • Comparison table across shared baseline definitions.
  • Metric plots across baseline definitions.
  • Automatic interpretation of amplitude, AUC, and FWHM sensitivity.

Wavelet tab

5. Metric plots

This tab visualizes wavelet metrics grouped by family. This avoids placing time, amplitude, AUC, and wavelet-scale metrics on a misleading single scale.

  • Event detection metrics.
  • Time-domain metrics.
  • Signal amplitude metrics.
  • Wavelet ridge metrics.
  • Area under the curve metrics.

Wavelet tab

6. Wavelet analysis

This tab displays wavelet-specific diagnostic outputs. It helps users verify whether detected events correspond to meaningful time-scale structures.

  • Continuous wavelet transform amplitude map.
  • Local maxima across scales.
  • Ridge-like event structures.
  • Diagnostic information for selected wavelet parameters.

Suggested Wavelet reporting sentence

Calcium transients were detected using the Wavelet Ridgewalking module in CalciumInsights. Events were identified as ridge-like structures in a continuous wavelet transform representation using user-defined scale, ridge connection, and event-filtering parameters. Post-detection metrics were calculated using the selected baseline definition, and baseline sensitivity was evaluated across multiple baseline definitions.
